PHP2Shell Radar 1.0.0 combines equivalent results for the same final website
when their PHP assessments agree. All checked addresses remain available in
site details and exports. Closing the Windows app now explicitly ends its GUI
process after a running scan stops.

The release includes a portable Windows GUI executable and a Linux x64 archive,
with SHA-256 checksums.

Enter a domain to discover reachable websites and identify PHP signals.
Optional active checks can confirm a repeated pre-fix PHP session behavior.
Read the in-app help before enabling checks that may affect a PHP worker.

See the [README](https://github.com/Secragon/php2shell-radar#readme) for
installation, result meanings and assessment limits.
